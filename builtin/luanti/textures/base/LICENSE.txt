Luanti's base texture pack, copied unchanged from
https://github.com/luanti-org/luanti (textures/base/pack), so that a game's
HUD -- heart.png, bubble.png, blank.png and the rest -- draws on a fresh
install without the user copying anything ([FIRST_RUN]).
